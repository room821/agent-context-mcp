# Agent Context Graph Viewer

User: developer defining one Agent Context Graph
Job: see the graph, edit a Pod contract, and save the same graph artifact
Done when: the user can select a node, change stability/capabilities, and save
the result back to the single YAML manifest

The canvas is primary. Provider URLs, event names, and raw serialized YAML are
inspector details; they should not compete with the graph.

- surface: `#0d1b2a`
